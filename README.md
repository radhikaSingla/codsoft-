# Titanic Survival Prediction 🚢

## Objective
Predict whether a passenger survived the Titanic disaster using machine learning.

## Steps Performed
- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- Model Training (Random Forest)

## Features Used
- Pclass
- Sex
- Age
- Fare
- Embarked
- FamilySize
- IsAlone

## Model Performance
Accuracy: ~75–85%

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
