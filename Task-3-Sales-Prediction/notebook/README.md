#  Sales Prediction using Linear Regression

## Overview

This project predicts product sales based on advertising expenditure using machine learning techniques.

## 📊 Dataset Features

* TV Advertising Budget
* Radio Advertising Budget
* Newspaper Advertising Budget
* Sales (Target Variable)

##  Steps Performed

* Data Cleaning and Exploration
* Data Visualization (Pairplot & Heatmap)
* Feature Analysis
* Model Training using Linear Regression
* Model Evaluation using MAE, MSE, R²

## 📈 Key Insights

* TV advertising has the highest impact on sales
* Radio has moderate influence
* Newspaper has minimal effect

## 📊 Visualizations

* Pairplot for feature relationships
* Heatmap for correlation
* Feature importance graph
* Model performance metrics
* Actual vs Predicted graph

##  Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 🎯 Conclusion

The model successfully predicts sales with good accuracy, showing strong influence of TV advertising on sales.
